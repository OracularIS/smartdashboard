# 5) Home Page (Tenant Home)

After selecting a tenant, you land on the tenant **Home** page.

## Screen

![Home page](./images/03-home.png)

## What you can do from Home

- **View Dashboards** → Opens the Dashboards page
- **Data Management** → Manage dashboards, datasets, settings, and API key
- **API Documentation** → Integration examples for Upload APIs

These same pages are also accessible from the top navigation.
