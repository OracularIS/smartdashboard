# Smart Dashboard (Dashboards App) — Customer Guide

Welcome to **Smart Dashboard** — a secure, multi-tenant dashboard application that turns your operational data into interactive dashboards.

This guide is written for **customers/end users** (not developers). It explains what you can do in the app, how the screens work, and how to integrate external systems via the Upload APIs.

> Note: This documentation intentionally avoids internal implementation details.
