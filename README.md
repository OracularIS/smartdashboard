# Smart Dashboard (Dashboards App) — Customer Guide

Welcome to **Smart Dashboard** — a secure, multi-tenant dashboard application that turns operational data into interactive dashboards.

This guide is written for **customers and end users** (not developers). It focuses on the user experience: what each screen does, how data appears, and how to integrate external systems via the Upload APIs.

> Note: This documentation intentionally avoids internal implementation details.
